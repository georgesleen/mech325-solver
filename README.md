# mech325-solver

# Setup

The easiest way to contribute and use this package is with a virtual environment. Follow the steps below if unfamiliar.

1. Create a venv
- Linux

```bash
python3 -m venv .venv
```

2. Activate the virtual environment
- Linux

```bash
source ./.venv/bin/activate
```

3. Install requirements

```bash
pip install -r requirements.txt
```

# Style guide

```bash
black .
```

# Testing
Testing is done with pytest

```bash
pytest
```
